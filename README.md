# 🚗 Сайт автомойки А500

Современный многостраничный сайт для автомойки и детейлинг-центра с продвинутыми функциями.

## ✨ Реализованные функции

### 🎨 Визуальные эффекты
- ✅ **Анимированный счётчик статистики** — цифры "накручиваются" при появлении на экране
- ✅ **Слайдер "До/После"** — интерактивное сравнение результатов работы
- ✅ **Параллакс-эффект** — изображение на главной странице двигается при наведении
- ✅ **Лоадер при загрузке** — анимированный логотип при первой загрузке сайта
- ✅ **Плавные анимации** — элементы появляются при прокрутке

### ⚙️ Технические функции
- ✅ **Калькулятор стоимости** — расчёт цены с выбором типа авто и услуг
- ✅ **Онлайн-запись с календарём** — выбор даты и времени
- ✅ **FAQ секция** — раскрывающиеся вопросы-ответы
- ✅ **Интеграция с Telegram** — заявки автоматически отправляются в Telegram
- ✅ **Форматирование телефона** — автоматическая маска +7 (XXX) XXX-XX-XX
- ✅ **Плавающие кнопки** — WhatsApp и звонок всегда видны
- ✅ **Кликабельные отзывы** — ведут на Яндекс.Карты
- ✅ **Кликабельный адрес** — открывает страницу организации в Яндекс.Картах
- ✅ **Адаптивный дизайн** — идеально выглядит на всех устройствах

## 📱 Структура сайта

- **Главная** — hero-секция, услуги, отзывы, бренды, химия
- **Услуги** — полный каталог с ценами
- **Цены** — пакеты услуг + калькулятор стоимости
- **О нас** — информация, преимущества, статистика, FAQ, карта
- **Контакты** — форма заявки + календарь записи + карта

## 🚀 Установка и запуск

### Локальная разработка

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр продакшен-сборки
npm run preview
```

### Деплой на Vercel

1. Зарегистрируйтесь на [vercel.com](https://vercel.com)
2. Импортируйте репозиторий с GitHub
3. Vercel автоматически определит настройки (Vite)
4. Нажмите "Deploy"

## 🔧 Настройка Telegram бота

Для получения заявок в Telegram:

1. Создайте бота через [@BotFather](https://t.me/botfather)
2. Получите токен бота
3. Узнайте свой Chat ID через [@userinfobot](https://t.me/userinfobot)
4. Откройте `src/pages/Contacts.tsx`
5. Замените `YOUR_BOT_TOKEN` и `YOUR_CHAT_ID` на ваши значения

```typescript
const TELEGRAM_BOT_TOKEN = 'ваш_токен_бота';
const TELEGRAM_CHAT_ID = 'ваш_chat_id';
```
