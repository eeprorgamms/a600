# A500 — автомойка и уход за автомобилем

Сайт на React 18, TypeScript, React Router и Vite. Отдельные страницы: главная (\`/\`), услуги (\`/services\`), цены (\`/pricing\`), о компании (\`/about\`), контакты (\`/contacts\`).

## Локальный запуск

\`\`\`bash
npm ci
npm run dev
\`\`\`

Проверка без публикации:

\`\`\`bash
npm run check
npm run build
npm run preview
npm audit --audit-level=moderate
\`\`\`

Команда \`npm run check\` проверяет типы TypeScript и критические настройки сайта/безопасности без дополнительных пакетов. \`npm run build\` запускает эту проверку перед сборкой и генерацией HTML для пяти страниц.

## Данные и цены

\`src/config/site.ts\` — единый источник телефона, адреса, виджета Яндекс Карт, цен, услуг, галереи и SEO. Цены из открытой карточки организации являются ориентиром, не обещанием окончательной стоимости. Не возвращайте вымышленные тарифные пакеты и отзывы.

Иллюстративные фотографии в галерее взяты из Unsplash и **не изображают выполненные A500 работы**. Реальные снимки посетители могут посмотреть в [карточке A500 в Яндекс Картах](https://yandex.ru/maps/org/a500/73889912604/). Для использования фотографий из отзывов на собственном сайте потребуются необходимые разрешения.

## Публикация

Конфигурация \`vercel.json\` содержит \`"git": {"deploymentEnabled": false}\`. Пуши в рабочую ветку не должны автоматически запускать деплой. Сначала локальная проверка, затем одно ручное развёртывание после согласования. Основную ветку \`main\` не изменять без одобрения.

В Vercel: Framework Vite, Build Command \`npm run build\`, Output Directory \`dist\`. Адрес для SEO задаётся переменной \`VITE_PUBLIC_SITE_URL\` (HTTPS).

## Функции и безопасность

Сайт предоставляет ссылки на телефон, Яндекс Карты, страницы услуг и цен. **Он не принимает онлайн-запись**, не отправляет персональные данные через публичную форму, не содержит пользовательских аккаунтов и скрытой админки. Пример \`backend-russia/\` не подключён к публичному интерфейсу.

См. [документ о безопасности и выпуске](docs/A500_SECURITY_AND_RELEASE.md): модель угроз, CSP/HTTPS-заголовки, права на фотографии, тестирование браузеров и ограничения.
