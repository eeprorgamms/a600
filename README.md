# A500 — сайт автомойки и детейлинг-центра

Многостраничный сайт на **React 18, TypeScript, Vite, React Router и Tailwind CSS**.

## Страницы

- Главная — `/`
- Услуги — `/services`
- Стоимость — `/pricing`
- О компании — `/about`
- Контакты и маршрут — `/contacts`

Сайт адаптируется под мобильные устройства. Основные кнопки ведут к разделам сайта, звонку и карточке организации в Яндекс Картах.

## Установка и запуск

```bash
npm ci
npm run dev
```

Для сборки:

```bash
npm run build
npm run preview
```

Для размещения на Vercel: используйте фреймворк Vite, команду сборки `npm run build`, каталог результата `dist`. Файл `vercel.json` содержит настройки маршрутов и заголовков.

## Настройки

Основные данные собраны в `src/config/site.ts`:

- `brand`, `description` — название и описание;
- `contacts` — телефон, адрес, график и ссылки на карты;
- `services`, `packages`, `pricesVerified` — перечень услуг и стоимость;
- `images` — изображения;
- `seo` — адрес сайта;
- `legal` и `leads` — параметры формы обращения, если она будет использоваться.

Страницы не показывают неподтверждённые числовые цены, если `pricesVerified: false`. В этом случае стоимость предлагается уточнять по телефону.

## Обращения посетителей

По умолчанию запись осуществляется **по телефону**. В интерфейсе нет неработающей формы отправки, календаря с выдуманными свободными местами или открытой панели управления.

Для включения формы обращения потребуется отдельно подключить серверную доставку, указать контакт и сведения оператора персональных данных, а также настроить защиту от автоматических отправок. Пример серверного обработчика размещён в `backend-russia/`. Его наличие само по себе **не означает, что доставка заявок включена**.

## Маршрутизация и SEO

Используется `BrowserRouter`, отдельные метаданные для страниц и сборка HTML с предварительно сформированным содержимым. В ходе сборки генерируются `robots.txt` и `sitemap.xml`.

Публичный адрес указывается через `VITE_PUBLIC_SITE_URL` и должен быть HTTPS-адресом.

## Состав проекта

- `src/components/` — повторно используемые элементы;
- `src/pages/` — страницы;
- `src/config/site.ts` — данные сайта;
- `scripts/` — формирование HTML и SEO-файлов;
- `backend-russia/` — опциональный обработчик обращений;
- `docs/` — подробная техническая документация.

## Примечания

Перед использованием настоящих персональных данных следует проверить хранение, передачу и защиту данных. Перед заменой изображений — проверить права на них. Ключи и пароли не должны добавляться в репозиторий.
