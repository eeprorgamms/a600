# A500 — дизайн-ТЗ: Lando Norris × Automotive Care

**Версия:** 1.0, 23.11.2026  
**Статус:** спецификация дизайна, без изменений production  
**Проект:** `eeprorgamms/a600`, рабочая ветка `a500-modernization-review`  
**Референс:** https://ui.gradientdeck.com/styles/lando-norris  
**Важное ограничение источника:** изучено опубликованное описание системы Lando Norris на GradientDeck. Полное содержимое файла, выдаваемого кнопкой «Copy DESIGN.md», не удалось скачать отдельно; нижеследующее ТЗ сочетает подтверждённые токены системы и наши адаптационные решения для A500. Не считать это побайтовой копией оригинального DESIGN.md.

## 1. Цель

Преобразовать существующий пятистраничный A500 в выразительный автомобильный сайт с редакционным спортивным характером: контраст тёмного olive-black и тёплого off-white, акценты electric lime, сильные крупные заголовки, фотография автомобиля/процесса в центре внимания, аккуратные контурные линии. Сохранить функции, роутинг, конфигурацию, контакты, SEO, адаптивность. Не имитировать приложение по бронированию. **Не копировать логотип, портрет, подпись, номера, изображения и фирменные элементы Lando Norris.**

## 2. Что действительно указано в системе Lando Norris (GradientDeck)

- Mixed theme: тёмные блоки на Paddock Olive и светлые на Chalk Cream.
- Тонкие линии топографических контуров по фону.
- Signal Lime `#D2FF00` для CTA, небольших акцентных форм и финального свечения — крайне умеренно.
- Moss Lime `#B2C73A` для контрастных слов в декоративном serif.
- Mona Sans Variable: uppercase заголовки, слегка суженная ось `wdth≈93`, насыщенность `wght≈660–750`.
- Brier: контрастный display serif для отдельных слов, не для длинного текста.
- Небольшие фотографии-фрагменты с подписями, обводки карточек толщиной 1px; основной тёмный блок карточек — Visor Black.
- Отсутствие теней как основной принцип композиции.
- В исходном референсе присутствуют угловые вырезы в outline-карточках (на примере шлемов); для A500 это адаптируется на карточки кузовных работ.

## 3. Токены цвета (точные значения из опубликованной системы)

| Токен | HEX | Роль в A500 |
|---|---|---|
| `--color-dark` Paddock Olive | `#282C20` | hero, statement, CTA section, footer |
| `--color-black` Visor Black | `#111112` | фотогалерея, отдельные панели, overlay |
| `--color-light` Chalk Cream | `#F4F4ED` | главная светлая поверхность, прайс, контакты |
| `--color-sage` Sage Fog | `#DDE1D2` | заголовки на тёмном фоне |
| `--color-moss` Moss Lime | `#B2C73A` | выделение 1–2 слов в больших editorial заголовках |
| `--color-signal` Signal Lime | `#D2FF00` | одна главная CTA в области видимости, фокус/акцент |
| `--color-caption` Lichen Gray | `#B4B8A5` | подписи на тёмном фоне |
| `--color-muted` Stone Gray | `#B9BBAD` | дополнительные комментарии |
| `--color-line` Tarmac Gray | `#535450` | тонкие контуры на тёмных поверхностях |

**Контраст:** для lime-кнопок использовать текст `#111112` (GradientDeck указывает контраст 16.22:1). На кремовом фоне основной текст `#282C20`. Не применять Moss Lime как мелкий текст на кремовом фоне без проверки WCAG. Цвет Signal Lime нельзя превращать в заливку секций.

## 4. Типографика

**Источник:** Mona Sans Variable + Brier. Перед внедрением проверить источники/права на веб-использование. Если Brier недоступен по подходящей лицензии — использовать доступную контрастную serif-альтернативу и **не утверждать, что это точное повторение Brier**. Если Mona Sans Variable недоступен, выбрать лицензионный близкий гротеск с кириллицей.

- Display на десктопе 64–96 px (выбранный для A500 диапазон, не точный размер исходного сайта), line-height 0.93–1.05, uppercase для коротких фраз.
- H1 на мобильном 36–52 px, не менее 2–3 строк при естественном переносе, без обрезания.
- H2 40–64 px десктоп, 30–38 px мобильный.
- Body 16–18 px, line-height 1.5–1.65. Фактические данные, инструкции и цены — без uppercase.
- Serif выделяет одно эмоционально важное слово в крупных заголовках (например «точность», «детали»), а не служит основным текстовым шрифтом.
- **Кириллица обязательна**. До внедрения проверить качество начертаний на строках «А500», «Удаление вмятин без покраски», «Полировка», «Боровское шоссе».

## 5. Сетка и графическая система — адаптация для A500

- Ширина контейнера ~1280 px, горизонтальные поля 24–48 px на desktop; 16–20 px на мобильных.
- Пространственный ритм: 8-пиксельная сетка. Desktop секции 88–136 px по вертикали; mobile 56–80 px.
- Чередование **темно → светло → темно → светло**, не более двух последовательно одинаковых крупных поверхностей.
- Основные карточки плоские, обводка 1 px, radius до 8 px. Угловые вырезы допустимы только как единый модульный стиль, не повсюду.
- Геометрические топографические линии: SVG/CSS узор с контрастом 4–8% поверх секций; не перекрывать текст, снижать детализацию на смартфонах.
- Жёстко исключить текущие большие размытые blobs, фиолетово-голубые градиенты, тяжелые box-shadows, чрезмерные glow-эффекты, emoji вместо профессиональной иконографии.
- Анимация: reveal 250–450 ms, hover 150–220 ms; максимум один заметный motion-эффект на секцию; уважать `prefers-reduced-motion`.

## 6. Структура пяти страниц (содержимое и функции не теряем)

### `/` — Главная
1. **Hero full-bleed**: Paddock Olive, контурный узор, большой фотокадр автомобиля справа или фоновое изображение с затемнением, без наложения текста на светлые детали фотографии.
2. Above the fold: логотип А500, строка «АВТОМОЙКА / ДЕТЕЙЛИНГ / PDR», H1 в 2–3 смысловых фрагмента «ВНИМАНИЕ К / КАЖДОЙ ДЕТАЛИ», одно слово в serif lime; единственная lime CTA «Позвонить» (`tel:`). Вторичная ссылка «Услуги» — контурная.
3. **Услуги**: Chalk Cream, сетка 2×2 или 3×2 плоских карточек; фото/крупный номер 01–06, заголовок, краткое описание, «Подробнее». Для неподтверждённой цены только «Стоимость уточняется» или без цены.
4. **PDR / Точность без покраски**: тёмный editorial statement, диагональный/асимметричный фотокадр с подписью; не обещать результат без фактических оснований.
5. **Процесс**: кремовый фон, 3 шага: консультация → оценка → работы; без вымышленных чисел и гарантий.
6. **Результаты**: Visor Black, крупные фотографии работ, настоящий before/after только при наличии реальных исходников и согласий. Если фото нет, заменить честной секцией о процессе без пустой «галереи».
7. **Конечный CTA**: Paddock Olive, небольшой lime halo за блоком, телефон и адрес.

### `/services` — Услуги
- Cream hero с крупным uppercase заголовком; табы/якоря «Мойка», «Детейлинг», «PDR», «Защита» только для реально существующих категорий.
- Карточки с 1px border; в раскрытии конкретные работы и ограничения. Первый клик всегда имеет понятный результат.
- PDR и кузовные услуги — отдельный фото-редакционный блок, если есть подтверждённый контент.
- CTA ведёт к `tel:` либо к странице контактов, не к несуществующему checkout/booking.

### `/pricing` — Стоимость
- Cream фон и крупный типографический заголовок.
- Если `pricesVerified=false`, аккуратная таблица по услугам с «Стоимость по запросу» и рабочим звонком; убрать внутренние служебные объяснения.
- Если подтверждённые цены появятся — таблица с категориями автомобиля, понятными единицами, «от» при реальной вариативности, согласованность с калькулятором.
- Разделительные линии вместо теней. Контрастная lime CTA после таблицы.

### `/about` — О компании
- Оливковый headline hero, широкая фактическая фотография пространства или процесса.
- Ассиметричные editorial photo fragments с небольшими подписями (без несуществующих сотрудников и оборудования).
- Преимущества в формате numbered list 01–04 на кремовом фоне.
- FAQ сохранить в лаконичных accordion без лишней анимации.

### `/contacts` — Контакты
- Cream фон и очень крупный H1 «КОНТАКТЫ».
- Основная информация: реально подтверждённый номер **+7 (915) 002-08-09**; адрес **Москва, Боровское шоссе, 6к1**; часы работы не изобретать.
- Map CTA: https://yandex.ru/maps/org/udaleniye_vmyatin_bez_pokraski/44612503769/ .
- Карта как опциональный блок с видимой ссылкой, если iframe недоступен.
- Не показывать фейковый календарь, незаполненную форму либо CTA без обработчика.

## 7. Основные элементы интерфейса

**Header:** Paddock Olive, фирменный текст A500 (без копирования чужого логотипа), разделы главная / услуги / цены / о компании / контакты; навигация текстом Sage Fog; lime CTA «Позвонить». На мобильном меню раскрывается поверх контента, клавиатурно доступно, имеет `aria-expanded`.

**Buttons:** `primary` Signal Lime + Visor Black текст, radius 8 px, padding 14–18 px / 24–32 px. `secondary` прозрачный фон + 1px border Lichen Gray, светлый/тёмный текст по контексту. Состояния hover/focus/disabled должны быть определены. Нет постоянного shimmer.

**Cards:** без теней; border 1 px; ровный baseline заголовков; карточки услуг с реальным действием. Иконки — SVG/простые монохромные пиктограммы вместо emoji.

**Photography:** автомобильный металл, вода, детейлинг, кузов крупным планом. Использовать реальные/лицензированные фото без копирования фотоматериалов Lando Norris. Изображения с фиксированным aspect-ratio, object-fit cover, оптимизированные AVIF/WebP и meaningful alt.

**Footer:** Paddock Olive + тонкие линии; тёплый светлый текст, телефон, адрес, ссылки на 5 страниц и карту. Единственный аккуратный radial lime halo, без декоративного «дисклеймера».

## 8. Техническая реализация и обратная совместимость

- Сохранить **React + TypeScript + Vite + Tailwind**, BrowserRouter и маршруты.
- Внедрить семантические CSS custom properties в `src/index.css`, при необходимости классы компонентов `a500-*`; избегать сотен точечных глобальных override (`.bg-blue-700`).
- Данные фирмы — исключительно `src/config/site.ts`; дизайн-токены отделить от данных и проверить контрастность.
- Компоненты: `SiteHeader`, `SiteFooter`, `PrimaryButton`, `SectionHeading`, `ServiceCard`, `EditorialPhoto`, `SectionContour` (наименование адаптационное, не из оригинального источника).
- Сохранять все кликабельные `tel:`, ссылки на карту и 5 маршрутов. Не вводить скрытые платные зависимости.
- Оставить поисковые метаданные/SEO-маршрутизацию, проверять прямое открытие URL.
- Соблюдать `prefers-reduced-motion`, фокус виден, размеры tappable элементов не менее ~44×44 px, нет horizontal overflow на 320 px.
- `font-display: swap`, разумный subset кириллицы, локальная загрузка только после проверки лицензий и прав.
- Изменения в branch, Vercel preview, публикация production только после согласования.

## 9. Критерии приемки дизайна

1. На desktop (1440×900), tablet (768×1024), mobile (390×844 и 320×568) нет горизонтального скролла, перекрытий и обрезания CTA.
2. Пять страниц визуально согласованы: палитра, типографика, фоновые линии, карточки, кнопки.
3. Доминирует тёплый off-white + olive-black; Signal Lime используется преимущественно для CTA, а не массовой заливки.
4. Нет стандартных синих кнопок, блобов/переливающихся градиентов, тяжёлых теней, emoji в карточках.
5. Контраст текста не ниже WCAG AA, фокус видимый, управление клавиатурой; `prefers-reduced-motion` выключает декоративную анимацию.
6. Все навигационные и контактные элементы реально работают, отзывы и цены не вымышлены, не показывается неподключённая запись.
7. Проверить сборку `npm run build`; проверить ошибки консоли, загрузку изображений и Lighthouse на реальном preview.
8. Производительность: ориентир Lighthouse Performance 90+ на desktop и 80+ на mobile при реалистичных условиях; это **цель, не гарантированный результат**, и подтверждается только измерением.
9. Нет изображений/логотипов/шрифтов без подтверждённых коммерческих прав.

## 10. Порядок разработки

1. Дизайн-токены + типографический прототип (русский текст, mobile first).
2. Header + Footer + Button + Section/Contour + ServiceCard.
3. Главная страница — подтвердить визуальное направление на preview.
4. Остальные четыре страницы в порядке `/services`, `/pricing`, `/about`, `/contacts`.
5. Оптимизация фотографий, адаптивность, доступность, SEO-регрессия и итоговый аудит.
6. После утверждения — отдельно согласованная публикация основного сайта.

**Что не следует переносить из исходного сайта Lando Norris:** личный бренд спортсмена, чужие фотографии и подписи, фирменный логотип, конкретную структуру магазина шлемов, сложный scroll-jacking, чрезмерные motion-эффекты, любые тексты или эмблемы защищённого бренда.

**Отношение к источникам:** цвета, семейства шрифтов, контурные линии, характер карточек и принцип отсутствия теней — основаны на опубликованном описании GradientDeck; размеры, сетки, структура пяти страниц, UX и критерии приемки — проектные рекомендации для A500.
